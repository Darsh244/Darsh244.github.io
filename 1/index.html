1. Part 1: Find shortest distance from a point to a function

Given a specific point $(x_0, y_0)$, there are 2 ways to find the shortest distance from that point to a function $f(x)$ - analytically (using calculus) or numerically (using iterative algorithms). This project will solve both the analytical approach and the numerical approach for the function $y = x^2 + 5$ and for the points $(0, 0), (-4, 0), (-8, 0), (2, 0), (6, 0)$.

1.1 The Objective Function

The euclidean distance d between a given point $(x_0, y_0)$ and any point $(x, y)$ on a function's curve is given by: $$d = \sqrt{(x-x_0)^2 + (y - y_0)^2}$$ However, because a square root is expensive to calculate, computer algorithms always optimize the squared distance (D) instead. $$D(x) = (x-x_0)^2 + (f(x)-y_0)^2$$ The goal of this project is to find the point $x$ that minimizes $D$, which also minimizes $d$ and therefore gives the shortest possible distance.

1.2 The Analytical Approach

Consider the function $y = f(x) = x^2 + 5$ and a specific point $(x_0, y_0)$. Since this function is smooth and differentiable throughout its domain, we can solve for the exact shortest distance using calculus. First, we take the derivative of the squared distance function $D(x)$, $$D'(x) = 2(x-x_0) + 2(f(x)-y_0)f'(x)$$ Then, we equate the derivative to zero to find the critical points, ie the values of $x$ for which $D(x)$ is minimum. $$ \begin{aligned} D'(x) &= 0 \\ &\implies 2(x-x_0) + 2(f(x)-y_0)f'(x) = 0 \\ \end{aligned} $$ Simplyfying the expression and solving for x, we get, $$x = x_0 - f'(x)(f(x)-y_0)$$ For the given function $f(x) = x^2 + 5$, it's derivative is $f'(x) = 2x$. Substituting these values in the above expression, we have, $$ \begin{aligned} x &= x_0 - 2x(x^2 + 5 - y_0) \\ &\implies x = x_0 - 2x^3 - 10x + 2xy_0 \\ &\implies 2x^3 + 11x - 2xy_0 - x_0 = 0 \end{aligned} $$ This gives the main equation that will be used to determine the minimum distance for each point in the analytical approach. $$ \boxed{2x^3 + 11x - 2xy_0 - x_0 = 0} \tag{1} $$ For each point $(x_0, y_0)$, the general process is to substitute the values of $x_0$ and $y_0$ into Equation (1). This gives the value of $x$ for which $D(x)$, and hence $d$, is minimized. The resulting value of $x$ is then substituted back into the original distance formula to obtain the minimum distance.

1.3 Numerical Approach

Solving $D'(x) = 0$ symbolically can be impossible when $f(x)$ is complicated. Numerical root-finding and optimization algorithms avoid this by approximating the minimizer iteratively. Two algorithms are used here.

1.3.1 Algorithm A: Newton-Raphson Method

If the first and second derivatives of $f(x)$ are easy to compute, Newton's method can be applied to $D'(x) = 0$. With $D(x) = (x - x_0)^2 + (f(x) - y_0)^2$:

$$D'(x) = 2(x - x_0) + 2\,(f(x) - y_0)\,f'(x)$$ $$D''(x) = 2 + 2\,f'(x)^2 + 2\,(f(x) - y_0)\,f''(x)$$ $$x_{k+1} = x_k - \frac{D'(x_k)}{D''(x_k)}$$

Iteration stops when $|x_{k+1} - x_k|$ falls below a tolerance, and the shortest distance is computed from the final $x$. 

def find_distance_newton(x0, y0, f, df, ddf, initial_guess=0.0,
                         tolerance=1e-7, max_iter=100):
    x = initial_guess
    for _ in range(max_iter):
        # D'(x)
        D_prime = 2 * (x - x0) + 2 * (f(x) - y0) * df(x)
        # D''(x)
        D_double_prime = 2 + 2 * (df(x)**2) + 2 * (f(x) - y0) * ddf(x)
        # Newton-Raphson update step
        next_x = x - D_prime / D_double_prime
        if abs(next_x - x) < tolerance:
            x = next_x
            break
        x = next_x
    shortest_distance = ((x - x0)**2 + (f(x) - y0)**2)**0.5
    return shortest_distance, x

1.3.4 Algorithm B: Golden Section Search

If the derivatives of $f(x)$ are unknown but the search can be restricted to an interval $[a, b]$ containing the minimum, Golden Section Search finds the minimum of $D(x) = (x - x_0)^2 + (f(x) - y_0)^2$ using only function values. It requires $D$ to have a single minimum inside $[a, b]$.

Two interior points are placed using the golden ratio $\varphi = \frac{1 + \sqrt{5}}{2}$, with $\text{resphi} = 2 - \varphi \approx 0.3820$:

$$x_1 = a + \text{resphi}\,(b - a), \qquad x_2 = b - \text{resphi}\,(b - a)$$

If $D(x_1) < D(x_2)$ the minimum lies in $[a, x_2]$, so $b = x_2$; otherwise it lies in $[x_1, b]$, so $a = x_1$. Each step shrinks the interval by a factor of about $0.618$ and reuses one interior point, so only one new evaluation of $D$ is needed per iteration. The search stops when $b - a$ falls below a tolerance, and the result is the midpoint $x^* = (a + b)/2$. 

import math

def golden_section_search(x0, y0, f, a, b, tolerance=1e-7):
    phi = (1 + math.sqrt(5)) / 2
    resphi = 2 - phi
    x1 = a + resphi * (b - a)
    x2 = b - resphi * (b - a)
    def dist_sq(x): return (x - x0)**2 + (f(x) - y0)**2
    f_x1 = dist_sq(x1)
    f_x2 = dist_sq(x2)
    while abs(b - a) > tolerance:
        if f_x1 < f_x2:
            b = x2
            x2 = x1
            f_x2 = f_x1
            x1 = a + resphi * (b - a)
            f_x1 = dist_sq(x1)
        else:
            a = x1
            x1 = x2
            f_x1 = f_x2
            x2 = b - resphi * (b - a)
            f_x2 = dist_sq(x2)
    best_x = (a + b) / 2
    return math.sqrt(dist_sq(best_x)), best_x

2. Part 2: Fitting to an equation

We are given the points $(0, 0.5)$, $(2, 3.5)$, $(1, 1.5)$, $(3, 7.5)$, and want to fit a line $y^*(x) = c_0 + c_1 x$, and a parabola $y^*(x) = c_0 + c_1x + c_2x^2$ by minimizing the min squared error of the fitted functions.

2.1 Fitting a line

The error at each point is:

$$e(x) = y^*(x) - y(x) = c_0 + c_1 x - y(x)$$

We want $c_0, c_1$ that minimize the min squared error over all points:

$$P(c_0, c_1) = \sum \|e(x)\|_2^2$$

Substituting the four points:

$$P(c_0, c_1) = (c_0 - 0.5)^2 + (c_0 + 2c_1 - 3.5)^2 + (c_0 + c_1 - 1.5)^2 + (c_0 + 3c_1 - 7.5)^2$$

2.1.2 Analytical Solution

Setting the partial derivatives to zero:

$$\frac{\partial P}{\partial c_0} = 0 \;\Rightarrow\; 2(c_0 - 0.5) + 2(c_0 + 2c_1 - 3.5) + 2(c_0 + c_1 - 1.5) + 2(c_0 + 3c_1 - 7.5) = 0$$ $$\Rightarrow\; 8c_0 + 12c_1 = 26 \;\Rightarrow\; 4c_0 + 6c_1 = 13$$ $$\frac{\partial P}{\partial c_1} = 0 \;\Rightarrow\; 2(c_0 + 2c_1 - 3.5)(2) + 2(c_0 + c_1 - 1.5) + 2(c_0 + 3c_1 - 7.5)(3) = 0$$ $$\Rightarrow\; 12c_0 + 28c_1 = 62 \;\Rightarrow\; 6c_0 + 14c_1 = 31$$

Solving these two equations simultaneously:

$$c_1 = 2.3, \qquad c_0 = -0.2$$ $$y^*(x) = -0.2 + 2.3x$$

The minimum squared error is $P(-0.2, 2.3) = 2.3$

2.1.3 Numerical Solution: Newton-Raphson

From $8c_0 + 12c_1 = 26$ and $12c_0 + 28c_1 = 62$, the partial derivatives and second partials are:

$$\frac{\partial P}{\partial c_0} = 8c_0 + 12c_1 - 26, \qquad \frac{\partial^2 P}{\partial c_0^2} = 8$$ $$\frac{\partial P}{\partial c_1} = 12c_0 + 28c_1 - 62, \qquad \frac{\partial^2 P}{\partial c_1^2} = 28$$

Each iteration optimizes one parameter at a time: first $c_0$ using the current value of $c_1$, then $c_1$ using the just-updated $c_0$:

$$c_0^{(n+1)} = c_0^{(n)} - \frac{\partial P(c_0^{(n)}, c_1^{(n)})/\partial c_0}{\partial^2 P/\partial c_0^2} = c_0^{(n)} - \frac{8c_0^{(n)} + 12c_1^{(n)} - 26}{8}$$ $$c_1^{(n+1)} = c_1^{(n)} - \frac{\partial P(c_0^{(n+1)}, c_1^{(n)})/\partial c_1}{\partial^2 P/\partial c_1^2} = c_1^{(n)} - \frac{12c_0^{(n+1)} + 28c_1^{(n)} - 62}{28}$$

Initial guess: $(c_0^{(0)}, c_1^{(0)}) = (0, 0)$.
